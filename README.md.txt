# Titanic Data Analysis

## Overview
This project analyzes the Titanic passenger dataset to explore survival patterns. It uses Python, Pandas, and Seaborn/Matplotlib for data analysis and visualization.

## Dataset
- Source: [Titanic dataset – DataScienceDojo](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)
- File: titanic.csv

## Project Structure
- titanic_analysis.ipynb → Jupyter Notebook with analysis
- titanic.csv → Dataset
- titanic_analysis.py → Python script version

## Key Findings
- Women had a higher survival rate than men.
- First-class passengers survived more than third-class passengers.
- Children had slightly better chances than adults.

## How to Run
1. Open titanic_analysis.ipynb in Jupyter Notebook or Google Colab.
2. Make sure titanic.csv is in the same folder.
3. Run all cells to reproduce analysis and charts.
